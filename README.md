# Rovilyn Castrodes — Portfolio

Portfolio of Rovilyn Castrodes, a 21-year-old BSCS 3B student and frontend developer from Guio-ang, Guindulman, Bohol. Projects, certificates and skills are mock content for a class project; the Facebook and Gmail contacts are real.

**Stack:** React 18 · Vite · Tailwind CSS · AOS · Framer Motion · lucide-react · React Router · MUI · SweetAlert2

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # static site in ./dist
```

Content lives in `src/data.js`. Pushing to `main` deploys to GitHub Pages through `.github/workflows/deploy.yml` (set **Settings → Pages → Source** to **GitHub Actions**). Comments on the contact page are saved in the visitor's browser only.
